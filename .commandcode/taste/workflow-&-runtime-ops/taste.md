- When an image upload is reported as still failing "padahal ukuran di bawah 2MB", size is usually not the cause in this Flutter + Node/multer stack: Dart's `http.MultipartFile.fromBytes` omits Content-Type unless `contentType:` is passed, so the server receives `application/octet-stream` and its image-only mimetype validation (multer, JPG/PNG/WebP/GIF) rejects the part with 400 regardless of byte size — proven by live API tests posting the identical PNG as octet-stream (rejected) vs image/png (accepted). Durable fix: map the filename extension to the MIME type and set `contentType:` on every multipart image part (fallback `image/jpeg` for camera/gallery files), done once in the single shared send method so both add and edit flows are covered. Confidence: 0.7
